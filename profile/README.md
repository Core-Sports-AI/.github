## What Core does

Film a match, upload it, and Core turns the video into a report you can act on: where you win and lose points, how you move around the court, which patterns repeat, and what to work on next.

**Squash analysis is available today. Pickleball is in beta.**

| | |
|---|---|
| **See where you win and lose points** | Rally, shot and court-position patterns read from your own match video. |
| **Practice with a model of your game** | A Digital Twin built from your measured matches, so you can test a game plan before you play it. |
| **AI finds the patterns. Coaches fix them.** | Coaches get the same evidence the player sees, so feedback starts from what actually happened. |
| **One roster. Every player.** | Academies and organizations follow every player's matches and progress in one place. |
| **Film it right** | Guidance on where to put the camera so the analysis can measure what matters. |

## How we build it

- **Measured, not guessed.** Every number is labelled as measured or estimated, and when the video cannot support a number we leave it out instead of inventing one.
- **Computer vision on real match footage.** Court, player, ball and racket tracking run on GPUs, then turn into rallies, shots and movement.
- **Checked against hand-labelled footage.** We evaluate each change against matches that people have labelled by hand, and we keep what improves the result.
- **Built for the people who use it.** Athletes get a short, visual report. Coaches get the detail behind it.
